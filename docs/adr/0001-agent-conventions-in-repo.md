# Context
Project conventions are spread across contributor documentation and
team knowledge. Agents and new contributors need relevant guidance.

# Decision
Keep a source-backed conventions inventory, concise Cursor rules,
and root/module AGENTS.md files in the repository.
Use automated checks for requirements that can be checked reliably.

# Consequences
Instructions can be reviewed and versioned alongside code.
Scoped rules reduce unnecessary context.
The team must maintain them as the project evolves.
Rules guide agents but do not guarantee compliance.
Our initial comparison showed broader test execution with instructions,
but did not establish a clear improvement in code correctness.
